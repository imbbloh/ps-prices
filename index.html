How it works: the title is sent to your Render backend, which reads each region's official PlayStation Store price; this page then converts to your chosen currency using live rates (open.er-api.com). A grey currency badge (e.g. USD on Mexico) means that store lists in a currency other than its own — still a real price, so it is ranked normally. A ⚠ marks a currency that isn't valid for the region at all; those rows sit below the ranking.
Missing regions? Search has to guess which store entry you meant. For an exact match, paste the game's store URL instead — e.g. store.playstation.com/en-in/concept/10014719. Concept links work in every region, so they resolve far more stores than a title search.
Note: buying a cheaper region's price needs a PSN account set to that region + its gift-card credit.
